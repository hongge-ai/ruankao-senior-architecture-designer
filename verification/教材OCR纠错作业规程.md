# 教材 OCR 纠错作业规程（第 10 章试点固化）

- 生效：2026-10-26；依据：AGENTS.md「教材 OCR 内证纠错」「教材来源限制」条目；首例：第 10 章试点（提交 `b706b9a`）。
- 适用：`content/01-系统架构设计师教材-清洗版/`。大纲（整页扫描件）与真题不适用。
- 性质：本规程是 AGENTS.md 的作业细则，与 AGENTS.md 冲突时以 AGENTS.md 为准；与[《教材核查与图表复原作业规程》](./教材核查与图表复原作业规程.md)并行——后者管扫描件核查（大纲、教材 32 页整页扫描覆盖页），本规程管 OCR 内证纠错，两者结论不得互相冒充。

## 1. 底本与证据边界

1. 底本是入库教材 PDF 的 **OCR 文本层**（`sources/01-系统架构设计师教材/`），页面渲染文字与之一致；**不是原书扫描图像**。
2. 教材 PDF 中 32 页为整页扫描覆盖页，渲染页即扫描页，可作扫描证据；其余页面不能（见[源文件身份核查-教材PDF为OCR重建文本.md](./源文件身份核查-教材PDF为OCR重建文本.md)）。
3. 本规程产出的修复只表示「在现有 OCR 底本上的可判定推断修复 / 最佳可用修复」，**不是原书事实**：
   - 不得登记「原书勘误」，不得把 OCR 形态判为原书印错；
   - 不得声称某章已完成扫描件核查或已还原原书；
   - 取得真实扫描件后，按[教材errata待重核清单.md](./教材errata待重核清单.md)与[教材OCR未决清单.md](./教材OCR未决清单.md)回图裁决。

## 2. 六档分诊

| 档 | 判据 | 处置 | 置信 |
|---|---|---|---|
| N | 版式/空格/列表编号/全半角宽度/代码标记/标题层级等归一，不改变文字 | 不改文字，记 N | — |
| K | OCR 文本明显是工件（误识、漏字、错字、粘连、公式/下标/字符残缺），清洗稿写法是明显正确修复 | 保留清洗稿，记 K | A 高 / B 中 |
| R | OCR 文本可读且合理，清洗稿只是改写、润色、换词、改标点、调序 | 回退到 OCR 文本，记 R | — |
| C1 | 无唯一解，但可由全书内部证据反推（同词多处出现、图题/表格/正文互证、公式结构唯一） | 修，记 C1 | 高 |
| C2 | 外部权威来源可证（标准文档、论文、权威百科、出版社/作者资料），至少两源 | 修并记来源，记 C2 | 中高 |
| C3 | 无法判定（标点种类、图表标签选词、书中独有写法、前后不一） | 保留原样，记 C3 并给候选/风险 | 低～中 |

- **优先级**：以 OCR 文本为底；清洗稿改写只有在对 OCR 工件时才保留；不把「更通顺/更正确」当作改回清洗稿的理由。
- **一条改动只记一个档**：同时符合多档时取最保守档，并在 evidence 说明。
- **术语**：对外一律写「N/K/R/C1/C2/C3 六档」；K 的 A/B 是置信度，不是档位；不得把六档简写成「A/B/C 分档」。

## 3. 逐类规则

### 3.1 术语、缩写、人名、公式名

- C2：至少两源（记 URL + 访问日期）；来源冲突未决时保留原样并记 C3。
- 不得引用盗版全文、下载链接或访问凭据；不得据领域常识补写原书未印内容。
- 只改可证的字串，不改句子结构；有内部互证时优先按 C1。

### 3.2 标点种类

- 以 OCR 标点为底，只修明显语法/结构错误（如句末结构要求句号而 OCR 缺、并列层次错误）；其余记 C3。
- 不按「全书统一体例」主动改标点——底本无据时，统一体例本身即新的无据改动。

### 3.3 公式、下标、希腊字母

- 标准公式可复原的按 K/B 或 C1 处理；书中独有记号（残缺运算符、可疑缺口）保留原样并记 C3。
- 不得以数学「合理」为由补残缺符号。

### 3.4 图表

- 拓扑以页面背景栅格图的线条为据；图内标签是 OCR 文本，单独分诊（如 `triage-figures`）。
- 标签能由正文、图题、表格互证的按 C1；有外部标准来源的按 C2；不能判定者保留原样并记 C3。
- 修改标签须同步 SVG、正文引用与 `catalog/figures.json`；锚点唯一性由校验器断言。
- 版式/版位按 OCR 页面阅读顺序，不确定者记 C3，不做「更美观」的调序。

### 3.5 结构与版式

- N 类不入修订清单；R 类按 OCR 的段落切分、阅读顺序回退；图块位置以 OCR 页面顺序为底。

## 4. 记录与留痕（硬要求）

每章产出两份**入库**记录（`verification/`）：

1. 纠错记录 `教材OCR纠错记录-第X章.md`：分节修订汇总、档位与依据、errata 处置、未采纳/未决项。
2. 分诊明细 `教材OCR分诊明细-第X章.json`：一条一行，字段 `id / file / loc / ocr（原串）/ current（清洗稿现状）/ final（建议最终串，null=不改）/ class / confidence / evidence / sources`。

试点期 `tmp/` 下的工作副本（盲核报告、分诊草稿、裁片）**不构成证据**，证据以入库记录为准；`tmp/` 不入库。

errata 联动：

- 撤销/迁移条目须留完整快照 `教材errata撤销记录-第X章.json` + 迁移记录 md，二者与本记录互链。
- 保留的 `noted` 条目须有扫描覆盖页证据（写明物理页与手段）；无法给出证据者不得保留「原书如此」表述。
- 新增/保留条目仍受 `catalog/errata.json` 校验：anchor 在正文恰好一次、`record` 存在、条目 id 出现在该记录文件中。

正文不写核查或修订语言；来源、依据、置信度只入 `verification/`。

## 5. 与扫描件核查的边界

- 大纲、教材 32 页扫描覆盖页仍按《教材核查与图表复原作业规程》的扫描件口径执行；本规程不修改、不追认那些记录。
- 扫描覆盖页证据足以把某条从「待重核」升为「已复核」时，在 `catalog/errata.json` 的 note 与迁移记录中写明证据页与手段；否则维持待重核。
- 不得用 C1/C2 的推断修复反推原书印面，也不得把「修复后更合理」写成「原书如此」。

## 6. 试点与推广

- 首例：第 10 章（2026-10-26，提交 `b706b9a`）：10.1–10.7 全文、23 图 + 4 表 SVG、分诊 171 条（N 47 / K 40 / R 50 / C1 10 / C2 3 / C3 21）；撤销 errata 11 条、保留 `noted` 3 条；C3 与不可判定项登记于未决清单（26 行，含少量 N/C3 混合项，行数不等同 C3 档计数）。
- 第 1–9 章：另开工作分支按本规程分章执行；完成前不得声称已还原原书，也不扩列 `catalog/corpora.json` 的 `blind_checked_chapters`。
