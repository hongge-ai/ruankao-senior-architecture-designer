# 教材 OCR 纠错作业规程

本页说明如何按 [AGENTS.md 的清洗与校对标准](../AGENTS.md#教材-markdown-清洗与校对标准)维护教材。校对从现有 PDF 页面或 OCR 文本开始，范围可以是一条问题、一节或一批相关问题。

## 校对步骤

1. 从[正文总索引](../content/INDEX.md)进入目标章的索引，打开目标节。用 `source_pages` 定位印刷页，并核对 PDF 物理页、页脚或所在段落。
2. 阅读清洗稿、对应 PDF 页面或 OCR 文本。结合同段句义、公式推导、同术语的重复用法以及图表和正文的相互印证，判断问题能否修正。
3. 优先修正文义、符号、结构或图表关系错误，再整理影响阅读的识别噪声、断句和版式。能够判定的直接改入 Markdown；图表按[图表作业规程](./教材核查与图表复原作业规程.md)修入 SVG。
4. 有多种合理读法时，保留现有内容，将位置、候选读法和卡点记录到[教材 OCR 未决清单](./教材OCR未决清单.md)。复核后解决的编号移出待核表，在本次记录中保留编号和处置依据。
5. 将有判断成本的修订记录在 `verification/`，注明正文位置、PDF 物理页与印刷页、修改前后和依据。有表述变更涉及既有勘误或图表登记时，同步检查锚点和资产引用。完成后运行仓库主校验。
