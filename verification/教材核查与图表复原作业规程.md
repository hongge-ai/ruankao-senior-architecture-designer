# 教材核查与图表整理作业规程

本页是 [AGENTS.md 图表与公式处理规则](../AGENTS.md#图表与公式处理)的操作说明。以仓库现有 PDF 页面或 OCR 文本为底本，正文与图表可以在同一节内互相印证。

## 定位与整理

1. 从章索引进入目标节，按 `source_pages` 查找 PDF 对应页。记录印刷页、PDF 物理页、图表号和正文引用的位置。
2. 核对页面可见线条、表格网格、OCR 标签和上下文。布局决定分组和连线时，从 PDF 页面核对；标签残缺时查找同图、同表或正文中的对应措辞。可判断的词、符号和结构直接修正。
3. 在独立 SVG 中保留有依据的标签、连线端点及方向、分组和表格行列。局部无法判断时留空并在 `<desc>` 或核查记录写明；整体结构无法判断时保留题注和正文说明。
4. 按[资产目录约定](../assets/README.md)落盘，通过 Markdown 图片语法引用。新增 SVG 逐项登记到 `catalog/figures.json`；修订 SVG 时核对对应资产路径、唯一题注和记录链接。

## 渲染与独立核对

- 渲染 PDF 对应页与 SVG，检查标签是否截断、文字是否重叠、节点是否连到正确位置。可用 `pdftoppm -f <物理页> -l <物理页> -r 160 -png <PDF> <输出前缀>` 导出目标页。
- 将目标页或可定位的 OCR 片段、相关正文和渲染后的 SVG 提供给干净上下文的子代理，请其独立检查标签、分组、连线或单元格，并报告仍无法判定的位置。按发现修订后重新渲染核对。
- 在 `verification/` 记录实际处理的范围、依据、改动和复核结果。最后运行仓库主校验。

早期章记录引用的历史流程可在本页的 Git 历史中回查。当期校对记录从[核查索引](./README.md#教材逐章核查结果)进入。
