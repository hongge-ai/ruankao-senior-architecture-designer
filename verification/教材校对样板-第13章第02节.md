## 独立核对

使用 pdftoppm 渲染 PDF 对应页，用 resvg 分别渲染修订前后的 SVG。独立复核逐项确认箭头方向如下。

1. 用户 → View（实线）。
2. View → Presenter（虚线）。
3. Presenter → Model（实线）。
4. Model → Presenter（实线）。
5. Presenter → View（虚线）。
6. View → Presenter（虚线）。
7. View → 用户。PDF 的箭头方向可确认，线身模糊，SVG 沿用既有虚线。

节点、步骤标签和整体布局相符。SVG 中第 2、5 步的标签分开显示，第 5 步标签的白色描边会遮住小段虚线，但连线路径和箭头仍可辨认。
